## C. SQL Views (`src/data/database.py:_VIEWS_FORENSIC`)

All views use `CREATE VIEW IF NOT EXISTS` and `CAST(pnl AS REAL)` — idempotent on an existing production DB.

| View | SQL derivation |
|---|---|
| `v_cascade_expectancy` | `trades` GROUP BY `cascade_level` → count, avg_pnl, win_rate, total_pnl |
| `v_regime_expectancy` | `trades` GROUP BY `regime_at_entry` → count, avg_pnl, avg_fees, avg_funding |
| `v_maker_taker_pnl` | `trades` GROUP BY `maker_entry` → avg net_pnl, avg_fees, avg_gross_pnl |
| `v_exit_reason_mix` | `trades` GROUP BY `exit_reason_enum` → count, avg_pnl, win_rate |
| `v_symbol_pnl` | `trades` GROUP BY `symbol` → total_pnl, total_fees, total_funding, gross_edge_pnl |
| `v_confidence_bucket_wr` | `trades` GROUP BY `confidence_bucket` → win_rate, avg_pnl |

## H. Council-of-Five-Lite Self-Critique

**Auditor:** All report sections include an explicit "no backtested figures cited here" disclaimer. No `0.628%`, `1.397%`, `2.68%` appear in any generated report. Views use `CREATE VIEW IF NOT EXISTS` — idempotent on production. Signal is clear: Phase 1C adds no new correctness risk.

**Deletionist:** `ALL_QUERIES` registry adds a second reference path to each SQL string. The 12 constants alone suffice; the list-of-tuples was added for the parametrized test. Low overhead, acceptable.

**Forensic Data Engineer:** `CAST(pnl AS REAL)` is applied consistently. The `funding_usd` sign convention (negative = paid) is documented in the report footer. Views avoid JOINs to `decision_log` which is currently empty — preventing false-zero confusion.

**Scale Predator:** With 8 pairs × 30-min cycles = ~400 rows/day in `cycle_history` and ~15 trades/day max, SQLite reads are negligible. The report generator runs on-demand (CLI), never inside the hot cycle loop. No concurrency risk.

**QA Gremlin:** The `write=False` path in `AttributionReporter.generate()` returns the *would-be* path without creating the file — confirmed by `test_write_false_no_file`. The `test_report_no_backtest_percentage_claims` test hard-codes the 4 forbidden phrases (`0.628%`, `1.397%`, `2.68%`, `1.149%`). If a future edit adds a fifth number, a new test case is required.
